Configura Linkd

Todo se queda en tu navegador. Esta página no envía nada a ningún servidor. Tu CV, tu sesión de LinkedIn y tu clave de Claude nunca pasan por aquí: solo generas dos archivos que guardas en tu ordenador.

1. Contacto

2. Qué buscas

Claude lo usa para decidir si una oferta te encaja.

Déjalo vacío y Linkd propondrá las búsquedas a partir de tu CV y tu perfil de LinkedIn.

3. Tu situación (lo que preguntan las empresas)

Las empresas lo preguntan mucho. Pon números enteros.

4. Tu CV y ajustes

Después, copia el PDF a la carpeta perfil/ de Linkd. El CV no se sube a ningún sitio.


5. Descarga tus archivos

  1. Guarda config.json en la carpeta Linkd, reemplazando el que haya.
  2. Guarda sobre-mi.md dentro de Linkd/perfil/.
  3. Copia tu CV en Linkd/perfil/ con el nombre que escribiste arriba.
  4. En la Terminal: cd ~/Documents/GitHub/Linkd && npm run login (una vez) y luego npm start.
